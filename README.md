# Typing Game

A small browser typing game built with vanilla HTML, CSS and JavaScript (no dependencies). Type a set of random words as fast and cleanly as you can.

## Features

- Choose 10, 20, 30 or 50 words per game
- Live caret, wrong letters shown in place, and a shake on mistakes
- Score breakdown with tooltips explaining each bonus, plus accuracy and WPM
- Best score saved per word count (localStorage)
- Light and dark mode, and a font switcher
- Keyboard accessible: Tab through controls, Esc to restart, Enter to play again

## Scoring

- 5 points per word
- 5 bonus points per word typed with no mistakes
- Time bonus: finish in 1 / 1.5 / 2 / 2.5 seconds per word or less (+10 / +7 / +5 / +3)
- WPM bonus: 50 / 40 / 30 / 20 WPM or more (+10 / +7 / +5 / +3)

## Run

Open `index.html` in a browser (or use VS Code Live Server).
